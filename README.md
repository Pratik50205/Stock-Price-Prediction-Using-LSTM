# Stock Price Prediction using LSTM

## Project Description

In this project, we predict stock prices using a deep learning model based on Recurrent Neural Networks (RNNs) with Long Short-Term Memory (LSTM).

It is based on the historical stock price data of Apple Inc. (AAPL).


## Data

* Source: Yahoo Finance
* Stock: Apple Inc. (AAPL)
* Time Range: Jan 2019 - Dec 2024
* Features:

  * Open
  * High
  * Low
  * Close
  * Adj Close
  * Volume

## Technology Stack

* Programming Language: Python
* Libraries: NumPy, Pandas, Matplotlib, Seaborn, scikit-learn, TensorFlow/Keras
* API: yFinance

## Deep Learning Model

* Recurrent Neural Network (RNN)
* LSTM (Long Short-Term Memory)
* Dropout Layers
* Early Stopping

## Steps Involved

1. Data Extraction via yFinance API
2. Data Preprocessing
3. Splitting Training and Testing Data
4. Developing LSTM Model
5. Training of the Model
6. Prediction & Evaluation
7. Result Visualization

## Performance Measures

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)


## Execution Process

1. Load the notebook on Google Colab or Jupyter Notebook
2. Install Dependencies
3. Execute each cell sequentially
4. Observe the Output Visualizations


## Conclusion

The proposed model identifies and learns from the pattern of stock price movements and offers reliable predictions; however, it is important to note that the stock market is very volatile.
